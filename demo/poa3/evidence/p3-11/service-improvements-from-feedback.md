# Service improvements driven by feedback (extract)
_Illustrative — supports P3-11-2 (acting on feedback)._

## Analysis → action
- Feedback is analysed quarterly and fed into a service-improvement action plan.

## Examples traceable to feedback
| Feedback theme | Change made |
|---|---|
| Portal registration confusing | Simplified portal screens / step-by-step flow |
| VAT guidance unclear | Rewritten plain-language VAT guidance |
| Long contact-centre waits at peaks | Added callback option |

## Gap (why this is B, not A)
- Improvements are made, but **not every theme is closed-looped back to taxpayers**
  (i.e. "you said, we did" communication is partial).
