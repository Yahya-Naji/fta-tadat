# POA 3 demo pack — Maya (Supporting & Facilitating Compliance)

Illustrative demo data (plausible, **not official FTA documents**).

## How to use
1. Open `/agents/service`.
2. **Answers** → click **Load sample answers**, or paste from [`ANSWERS.txt`](./ANSWERS.txt).
3. **Evidence** → attach the matching file on each "Requested evidence" row (map below).
4. Click **Process evidence & score**.
5. Expected: mostly **A/B**, with **P3-12 ≈ C** (proactive accurate-reporting engagement
   still maturing) → **POA 3 ≈ C** (M1, lowest-wins). P3-9 shows numeric values
   (telephone ≈ 7 min, written ≈ 92%).
