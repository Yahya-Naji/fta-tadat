# POA 2 demo pack — Hamad (Effective Risk Management)

Illustrative demo data (plausible, **not official FTA documents**).

## How to use
1. Open `/agents/risk`.
2. **Answers** → click **Load sample answers**, or paste from [`ANSWERS.txt`](./ANSWERS.txt).
3. **Evidence** → attach the matching file on each "Requested evidence" row (map below).
4. Click **Process evidence & score**.
5. Expected: mostly **B**, with **P2-7-2 ≈ C** → **POA 2 ≈ C** (M1, lowest-wins).
